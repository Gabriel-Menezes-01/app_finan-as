## 📱 **Como Usar as Novas Funcionalidades**

### Criar Transferência para o Brasil:
1. Vá para **"Gastos Mensais"**
2. Toque na aba **"Transferências BR"**
3. Toque em **"Nova Transferência para o Brasil"**
4. Preencha valor em € (valor em R$ calculado automaticamente)
5. Salve a transferência

### Exportar para Excel:
1. Vá para a aba **"Relatórios"**
2. Toque no menu **⋮** no canto superior direito
3. Escolha **"Exportar Todas as Transações"** ou **"Exportar Resumo do Mês"**
4. Aguarde a geração do arquivo
5. Escolha onde compartilhar/salvar
